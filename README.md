# Paranice IT Command

Micrositio interactivo para presentar la solución del reto técnico IT de Paranice.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Desplegar en Vercel

1. Subir este folder a GitHub.
2. En Vercel, crear proyecto nuevo y seleccionar este directorio como root.
3. Usar estos valores:
   - Build command: `npm run build`
   - Output directory: `dist`

El sitio incluye enlaces descargables a los entregables generados en `public/artifacts`.
